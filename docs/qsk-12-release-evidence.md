# QSK-12 release evidence

A read-only observer runs after completion of targeted CI and Pages. It checks out only trusted default-branch code and reads source run, attempt-specific jobs/steps and run-scoped artifact metadata. Find the JSON in the QSK-12 workflow artifact and the summary in its Actions run. Source PR head SHA is not assumed to be checkout SHA; release certification requires main, a successful run and actual successful Deploy step. Historical certification is not current-live verification. Skipped/missing checks never mean pass. Existing test and deployment gates remain authoritative. No physical iPhone approval, private docs or raw logs are included. Pages archives the existing QSK-04 asset passport; feature screenshot evidence is linked when the existing impact router produced it. The observer does not rerun tests or alter deployment.
