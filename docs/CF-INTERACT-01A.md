# CF-INTERACT 01A — isolated geometry preflight
Extends the existing shared anchor module, not a second runtime system. Current outdoor and indoor callers remain unchanged. Version 1 accepts horizontal rectangular support pieces in semantic +Y up/+Z front coordinates, a native-frame yaw, exact GLB SHA, explicit nonoverlapping slots and rear-half contact anchors. Real slat gaps are preserved. The static bench extractor fails closed on unsupported glTF hierarchy; future arbitrary meshes need a proper scene-graph reader. Both generated height variants are geometry-only diagnostics, never catalog replacements. Original 64cm is a normal-seat negative control. 45cm and predeclared 42cm are candidates, not approved seating.
The preflight is a necessary-condition check only: height ceiling, actual planar support, slot, approach corridor callback and rigid metric transform. Width/depth are synthetic diagnostic rig inputs; full measured rig/action passports, joint limits, foot and hand support, actual collision and transitions belong to later gates. The external corridor callback must be supplied by the environment; this lab tests explicit clear/blocked inputs, not real navigation or body sweep. No reservation writes; no solver execution. FBIK R12 remains pinned to 6974fc7e91ee2b089bde79c701eee946da142b51. No production GLB, save, game wiring or deployment changes. Reproduction: node --test tests/cf-interact-01a.test.js; node --input-type=module -e "import {runProbe} from './tools/cf-interact-geometry.mjs'; runProbe()".
