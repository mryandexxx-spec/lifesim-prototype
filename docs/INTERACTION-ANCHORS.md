# Interaction Anchors — universal furniture interaction architecture (design + headless foundation)

Status 2026-11-14: proposed after real iPhone 0.7b.1 screenshot, and **foundation code committed**. Production sofa still uses existing `meshySofaVerticalLift` and manually sampled hip curve. This document **does not** claim the new solver has fixed the current image or been visual-QA tested.

## Problem

The previous sofa path couples 3 independent values:
1. The furniture seat center / cushion dimensions in `SOFA_LAYOUT`.
2. The procedural avatar's hardcoded `SOFA_POSE.y=-0.225`.
3. The Meshy clip `Sit_to_Stand_Transition_M` pelvis animation, transformed by its own skin-scale and another Y-correction.

Tweaking only the last Y-correction for a single couch is not reusable. It also does not guarantee believable feet/legs/hands contact.

## New contract

**Furniture surface metadata** is authored once for each *furniture asset or prefab*, not per user screenshot or per avatar:

```js
const couch = createSeatSurface({
  id:'living-couch',
  origin:{x:1.35,y:0,z:1.54},
  yaw:180, // furniture local +Z faces the sofa front
  width:2.53,
  depth:1.05,
  seatHeight:.35, // measured top of cushion
  slots:2, // allow multiple residents
  sideMargin:.4, // geometry clearance from armrests
  approachGap:.5,
  floorY:0
});
const place = seatSlot(couch,1);
```

**Character data** is authored or measured once per character/rig and *compatible animation*:
- rig-specific bone aliases (Humanoid / Mixamo mapping) for pelvis, legs, feet and optional hands;
- stable body/leg scale derived from original mesh dimensions, not animated AABB;
- pose-specific `contactLocal` for posterior/pelvis in current animation frame (plus sole markers);
- a generic compatible sitting clip (playable forwards/backwards) and an independent simulation state timeline.

**Contact solver**:
```js
const seatedRoot = solveSeatRoot({
  seat:place,
  contactLocal:characterPose.buttContact,
  scale:meshScale,
  yaw:place.yaw,
  clearance:.012
});
const blendedRoot = blendSeatRoot({
  freeRoot:standingRoot,
  seatedRoot,
  weight:sitContactWeight
});
```

The root placement is derived from a single contact equation for each frame: `seatWorldContact = avatarRoot + rotate(localContact*scale, seatYaw)`. **Do not add `SOFA_POSE.y` or another hardcoded couch lift** after this solve, or the double transform returns. Active seat slots remain game-state reservations; `lifesim.room01.v1` stays compatible.

## Planned render bridge (NOT YET IMPLEMENTED)

1. Resolve target sofa from action and reserved slot; acquire `seatSlot` contact and approach transform (already engine-agnostic).
2. Animate pose via the skinned clip with in-place root-motion extraction (movement belongs to the original game A* and interaction state, not the imported GLB hip translation).
3. Obtain bone/contact transforms *after* animation evaluation; compute root position to satisfy the target seat-contact constraint. For skinned mesh, pelvis bone origin is not necessarily where the butt touches the cushion. Calibrate a lightweight butt-contact marker once **per animation/rig**, or compute sample via skinned proxy region; do not use AABB or the knee point as substitute.
4. Apply a two-bone IK pass to each foot toward the ground targets generated by `seatFootTargets()`, with soft limits for knees/ankles and IK weight blended during sitting. Extend later to palms, bed and other objects.
5. Optional simple pelvis/seat collision proxy (capsule/sphere contacts) should reject remaining clipping into the cushion, armrests and back. This is a narrow contact-constraint system, not necessarily full rigid-body simulation.
6. Blend out constraints on stand-up, interruptions, pause, speed ×3, load from existing saves, and avatar mode switching. Separate controller from gameplay rules.

Furniture classes like sofa, armchair, bench can share the same solver. Other actions need compatible contacts: bed uses lying surface, mattress-side approach and left/right occupancy, fridge uses hand/object attachment points, shower uses entrance/inside/privacy states.

## What is already implemented

`src/interaction-anchors.js`: pure functions `createSeatSurface`, `seatSlot`, `solveSeatRoot`, `blendSeatRoot`, `seatFootTargets`, `smoothContactWeight` and yaw rotation. No runtime PlayCanvas dependency, no save change, no new GLB. `tests/interaction-anchors.test.js` covers different seat heights, chairs/couches orientation, two seat slots, 2 avatar sizes, floor foot targets, smooth blending and invalid geometry: 6/6 executed in V8 as of this change.

**Important limitation:** `seatFootTargets` computes desired goals but does NOT perform IK yet. `solveSeatRoot` assumes the supplied local contact marker is accurate for the evaluated animation frame. An arbitrary clip may still be anatomically incompatible with a furniture item (e.g. high stool); support clip selection by furniture category and joint-limit checks.
