# CAS-HEAD-V2-P3 · Леон и Ася

Эта итерация остаётся в draft PR #269. Модели предназначены для художественного просмотра в отдельной лаборатории.

P2 сохранял целое исходное лицо под полупрозрачным фрагментом и добавлял независимые накладки глаз и губ. Сетка фрагмента имела 402 открытых ребра. В P3 исходная модель обрезана на сечении шеи, а новый непрозрачный меш содержит затылок, уши, вековые и губные петли, углубления глазниц и рта. Шов совпадает с обрезанным телом по позициям и весам. Новые глазные сферы сидят за веками. Для каждого жителя запечён самостоятельный атлас кожи 1024², причёска моделируется отдельно.

- `build-heads.py` сохраняет нативные `.blend` с пятью shape keys и исходными действиями. MPFB v2.0.18 используется офлайн как донор проверенных хешами CC0 квадов и дельт. Цвет, пропорции, волосы, глаза и посадка шеи задаются для каждого жителя отдельно. Код MPFB и целый донор не входят в поставку.
- `assemble-glb.py` добавляет Blender-геометрию к исходным узлам и перенумеровывает индексы костей по именам. Исходные матрицы привязки, узлы, каналы и буферы 10/13 клипов сохраняются. Скрипт не меняет исходные GLB.
- `verify-p3.mjs` проверяет прежние инварианты, непрозрачность кожи, совпадение шва и весов, целостность рига, реальную геометрию и состояние крайних положений.
- `../p3-lab/smoke.mjs` запускает PlayCanvas 2.24.1 и сравнивает кадры при каждом из пяти морфов и их комбинации, переключает оригиналы и воспроизводит три клипа. Протестированные браузерные размеры 390×844 и 320×568.

```sh
blender -b --python-exit-code 1 -P art-review/cas-head-v2/p3/build-heads.py -- \
  --donor /path/to/mpfb2/src/mpfb/data --output /tmp/lifesim-p3
python3 art-review/cas-head-v2/p3/assemble-glb.py /tmp/lifesim-p3 art-review/cas-head-v2/p3-lab/assets
node art-review/cas-head-v2/p3/verify-p3.mjs
npm ci
npm install --no-save playwright@1.56.1
npx playwright install chromium --only-shell
node art-review/cas-head-v2/p3-lab/smoke.mjs
```

Художественное утверждение владельцем и проверка на физическом iPhone открыты. Основная игра, GitHub Pages и PR #145 остаются вне поставки.
