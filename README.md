# LifeSim 0.6c.4 — опоры при укладывании и подъёме

**Игра:** https://mryandexxx-spec.github.io/lifesim-prototype/

Переработана последовательность сна: разворот у длинного бока → шаги к краю → посадка с фиксированными стопами → подъём и перенос ног → укладывание вокруг неподвижного таза. Выход проходит в обратном порядке; новый маршрут ждёт окончания подъёма. Обе стороны доступны обоим жителям, два человека могут спать одновременно.

- Убрано второе сглаживание координат кровати. Положение тела и контактные суставы берутся из одной фазы, без разной задержки.
- Ноги используют двухзвенную IK с устойчивым направлением колена; подошвы сохраняют горизонтальное положение. Расчёт поворотов соответствует Euler-порядку PlayCanvas.
- Высота матраса уменьшена до .48, чтобы ноги достигали пола при посадке и вставании. Тумбочка в сцене действительно перемещена к изголовью, в соответствии с навигацией.
- Одеяла сложены на время посадки и подъёма и накрывают ноги после укладывания.
- Формат сохранений `lifesim.room01.v1`, `version:1` и свободный выбор `action.bedSlot` сохранены.

## Проверка

```sh
npm ci
npm test
```

PlayCanvas 2.24.1 используется как закреплённая dev-зависимость для геометрических тестов настоящих rig-трансформаций. В браузере остаётся тот же CDN, JavaScript ESM без обязательной сборки. Тесты проверяют обе модели и стороны, опоры стоп, повороты суставов без переворотов, паузу/отмену, неподвижный таз при укладывании и отсутствие пересечения выборок поверхности тела с матрасом. Автоматические проверки и геометрические просмотры не заменяют визуальную приёмку в Safari.

## Проверка на iPhone

Версия в заголовке: **prototype / 0.6c.4**. Отправить обоих жителей спать с разных сторон; проверить посадку, перенос ног, контакт тела с матрасом и одновременный сон. Затем разбудить одного, выдать ему новое действие и проверить, что сначала он садится на край, ставит стопы на пол и встаёт. Повторить для другой стороны; проверить паузу, ×3 и отмену в середине укладывания.

Реальная iPhone-проверка этой версии пока не проведена. Offline/cloud-save и миграция на TypeScript не реализованы. Лицензия оригинального кода не выбрана.
