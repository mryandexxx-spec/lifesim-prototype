# LifeSim 0.6b — более живая походка

Оригинальный стилизованный 3D-симулятор жизни для Safari на iPhone.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Что изменилось в 0.6b

После подтверждения владельцем работы свайп-камеры 0.6a («Все супер. Едем дальше») улучшена походка обоих жителей без изменения игровых правил.

- Ритм шагов привязан к **фактически пройденному расстоянию** по A* маршруту, включая скорость симуляции 1×/3×, а не к частоте кадров.
- Плавное начало/остановка. Бёдра и руки двигаются в противофазе; колено переносимой ноги сгибается сильнее. Стопа немного приподнимает носок на переносе шага и перекатывается на опорной фазе.
- Небольшой перенос веса через таз и корпус, с мягкой коррекцией высоты тела для контакта обуви с полом вместо прежнего выраженного искусственного подпрыгивания.
- Процедурная модель и старые плавные позы сохранены. Анимация ходьбы не подменяет сидение на диване, сон, холодильник, душ и общение; при паузе она заморожена.
- `src/locomotion.js` — чистая математика походки; `tests/locomotion.test.js` — новые регрессионные проверки.
- Для обоих жителей меняются только временные визуальные параметры; `localStorage` key `lifesim.room01.v1`, `version:1`, схема сохранений и автономность неизменны.

## Как проверить на iPhone

Открой страницу, проверь метку **prototype / 0.6b**. Отправь Алекса к холодильнику, Миру — к душу, посмотри на начало, движение в поворотах, остановку и смену направления. Сравни шаги на 1× и 3×; попробуй паузу в середине шага. Затем проверь принятую посадку/вставание на диван и свайп-камеру. Сообщи, если есть скольжение обуви или странные движения ног.

## Дальнейший утверждённый план

**0.6c:** подход к двуспальной кровати с обеих сторон и два независимых места для сна.
**0.6d:** корректная дверца холодильника, доставание и употребление еды.
**0.6e:** оригинальная приватная маска и анимация душа.
**0.6f:** общая визуальная полировка и регрессии. Эти этапы пока не выполнены.

## Технически

PlayCanvas 2.24.1 pinned CDN, браузерные JavaScript ES modules, GitHub Pages. Ядро симуляции отдельно от графики. Дополнительная ходьба опирается на готовые hip/knee/shoe pivots и pelvis/torso mesh, без создания новых мешей в кадре. Это лёгкая процедурная походка с приближённым ground-contact, **не** полноценная физическая IK или skinned mesh. Реальная iPhone-визуальная оценка этой версии ещё требуется. Offline/cloud saves нет, TypeScript не внедрён, лицензия собственного кода не определена.
