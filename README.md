# LifeSim 0.6a — свайповая камера

Оригинальный стилизованный 3D-симулятор жизни для iPhone Safari.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Новое в 0.6a
- **Один палец / мышь:** свайп по свободной части 3D-сцены перемещает обзор по комнате. Раньше этот жест только вращал камеру.
- **Два пальца:** смещение центра жеста поворачивает/наклоняет камеру; щипок меняет масштаб. При смене количества пальцев случайное нажатие предмета не должно срабатывать.
- **Сброс камеры ⌖:** возвращает центр, угол и масштаб. Границы панорамирования не дадут потерять квартиру.
- Старые взаимодействия с предметами, HUD, пауза/×3, Авто, отношения и сохранения остаются. Новых сохраняемых полей нет.
- `src/camera-controls.js` содержит отдельную геометрию управления без PlayCanvas, `tests/camera-controls.test.js` — регрессионные тесты.

## Дальнейший согласованный блок 0.6
После проверки 0.6a на iPhone: **0.6b** живая походка; **0.6c** двуспальная кровать (два реальных слота/подхода); **0.6d** холодильник (дверца/еда); **0.6e** душ (оригинальная privacy-маска и переодевание); **0.6f** совместные регрессии. Пока НЕ реализованы.

## Технически
PlayCanvas 2.24.1 CDN, JavaScript ES modules, GitHub Pages. Симуляция независима от рендера. Key localStorage `lifesim.room01.v1` и schema `version:1` неизменны. Нет offline/облачных сейвов и миграции на TypeScript. Лицензия собственного кода не выбрана. Только реальный iPhone-тест подтверждает удобство жестов.
