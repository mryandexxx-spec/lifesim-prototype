# LifeSim — Room 01 · 0.3.1

Оригинальный стилизованный 3D-симулятор жизни для **iPhone Safari**.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Новое в 0.3.1
- Справа появилась кнопка **«Авто ВКЛ/ВЫКЛ»**: можно отключить самостоятельные действия и оставить Алекса полностью под управлением игрока.
- Выбор сохраняется после перезапуска игры, а при создании новой жизни остаётся прежним. Ручные команды работают даже при выключенной автономности.
- После загрузки, завершения действия или повторного включения самостоятельности Алекс ждёт **12 секунд активного времени** без действий. Ускорение ×3 не сокращает задержку; пауза её останавливает.
- Отключение прекращает текущую автоматическую задачу, но не прерывает ручную.

## Новое в 0.3
- У Алекса появился характер: аккуратность, любовь к уюту и любознательность.
- Настроение зависит от потребностей и последних событий, может улучшаться после приятного занятия.
- Алекс запоминает до 12 последних завершённых действий.
- Возникают краткосрочные желания, которые влияют на самостоятельный выбор занятий.
- Нажми на карточку **Алекс** внизу экрана — увидишь настроение, желание, черты и воспоминания; желание можно выполнить прямо из панели.
- Старые локальные сохранения 0.1 и 0.2 поддерживаются, прежний ключ и версия формата сохранены.

## Возможности
Квартира, персонаж, четыре потребности, кровать, диван, душ, холодильник, сенсорная камера, A*-обход мебели, анимации-позы, игровое время, пауза/×3, автономное поведение, сохранения.

## Техническая структура
- `src/simulation.js` — независимое ядро жизненной симуляции.
- `src/psychology.js` — чистая модель характера/эмоций/желаний/памяти.
- `src/navigation.js` — A* и статические препятствия.
- `src/game.js` — PlayCanvas 3D, UI и управление касаниями.
- `index.html`, `styles.css` — адаптивный интерфейс.
- `tests/*.test.js` — регрессионные тесты.
- `.github/workflows/pages.yml` — тесты и автоматическая публикация GitHub Pages.

**Стек:** JavaScript ESM, PlayCanvas `2.24.1` по CDN, без обязательной сборки. TypeScript ещё не внедрён.

## Проверка
`npm test` — headless тесты; `node --check src/game.js` — синтаксис browser-модуля. Сайт доступен по HTTPS после успешного GitHub Pages workflow.

## Ограничения
Ранний прототип: один персонаж, четыре контекстных действия, упрощённые визуальные позы, статическая навигация и локальный `localStorage`. Нет облачных сейвов, offline service worker, отношений и дополнительных персонажей. Движок/шрифты грузятся из CDN. Нативного iOS-приложения пока нет.

Публичная доступность исходников не означает разрешения на их свободное использование. Лицензия собственного проекта не выбрана; PlayCanvas имеет MIT-лицензию.
