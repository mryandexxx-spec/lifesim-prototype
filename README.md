# LifeSim — Комната 01

Первый интерактивный прототип оригинального симулятора жизни для **Safari на iPhone**.

## Играть

После включения GitHub Pages в **Settings → Pages → Source: GitHub Actions** игра будет доступна по адресу:

**https://mryandexxx-spec.github.io/lifesim-prototype/**

Это адрес предполагаемой публикации, а не подтверждение того, что GitHub Pages уже включены.

## Возможности прототипа 0.1

- Полностью программно созданная 3D-квартира и стилизованный персонаж Алекс.
- Поворот камеры касанием; pinch-жест для приближения/отдаления; сброс камеры.
- Кровать, холодильник, душ и диван с интерактивными метками и действиями.
- Передвижение персонажа, игровые часы, голод, энергия, гигиена, досуг.
- Пауза, ускорение ×3, простое автономное поведение при низких потребностях.
- Локальное сохранение в `localStorage`, кнопка новой игры.
- Минимальный PWA manifest (полноценный offline пока **не** реализован).

## Архитектура

- `index.html` + `styles.css` — мобильный интерфейс.
- `src/game.js` — PlayCanvas, процедурная сцена, касания и интерфейс.
- `src/simulation.js` — независимые и тестируемые правила жизни; не импортирует движок.
- `tests/simulation.test.js` — тесты игровой логики на встроенном Node.js test runner.
- `.github/workflows/pages.yml` — тесты и публикация статической страницы.

Для раннего прототипа используем **ES modules без сборки**, PlayCanvas `2.24.1` через закреплённый CDN URL. Это сознательное упрощение, чтобы сразу запускаться в Safari и деплоиться без локальной среды разработки. TypeScript/Vite добавим, когда проверим работоспособность на реальном iPhone. Пока для первого запуска нужен интернет.

## Проверка и запуск локально

`npm test` — тесты симуляции. Чтобы открыть игру локально, используйте статический HTTP-сервер (`python3 -m http.server 8000`), затем зайдите на `http://localhost:8000`.

## Ограничения

Это технический прототип, а не готовая игра. Навигация прямолинейная без поиска пути и обхода мебели. Облачного сохранения и гарантии офлайн-режима нет. Сохранение браузера может быть очищено операционной системой. Графика и производительность **ещё не проверены на реальном iPhone**.
