# LifeSim 0.6d — холодильник, порция и перекус

**Игра:** https://mryandexxx-spec.github.io/lifesim-prototype/

После принятия владельцем исправленной кровати 0.6c.4 обновлён холодильник.

- **Подход:** обоим жителям доступна точка слева у ручки, герои поворачиваются к ней.
- **Дверь:** верхняя дверца и ручка вращаются на общей правой петле; сектор открывания зарезервирован в A* даже когда дверь закрыта, чтобы другие жители туда не заходили.
- **Последовательность:** поворот → открывание → движение руки к полке → перенос видимой порции с полки в руку → закрывание → поднесение еды ко рту, жевание и постепенное исчезновение перекуса.
- **Геймплей:** сытость повышается на этапе еды, а не до открытия. Восстановление сытости за всё действие оставлено прежним; холодильником пользуется один житель.
- **Прерывание и сохранения:** при отмене или новой команде дверца закрывается и бывший пользователь дожидается закрытия. Пауза останавливает анимацию; ×3 ускоряет течение игрового действия; после загрузки середина сценария восстанавливается из существующего `action.elapsed`. Формат `lifesim.room01.v1` / `version:1` не менялся.

## Проверка

```sh
npm ci
npm test
```

Добавлены `src/fridge-interaction.js` и `tests/fridge.test.js`: тесты проверяют коллизию дверцы, навигацию, геометрию PlayCanvas, видимость/перенос еды, завершение по времени, отмену/паузу, двух жителей и старые сохранения. PlayCanvas 2.24.1 pinned CDN, JavaScript ES modules без обязательной сборки.

## Проверка на iPhone

Новая версия в шапке: **prototype / 0.6d**. Отключить Авто, выбрать Алекса, затем холодильник и «Перекусить»: проверить, что герой подходит к ручке слева, дверца не пересекает его тело, порция сначала на полке, потом в руке, дверца закрывается до еды, рука поднимается ко рту, еда исчезает. Повторить за Миру. Проверить отмену посередине действия, паузу, ×3 и сохранение/перезапуск в процессе еды. Также быстро проверить, что диван и кровать работают по-прежнему.

**Статус:** публикация через GitHub Actions; реальная визуальная приёмка 0.6d на iPhone ожидается. FPS/нагрев и Safari E2E не измерены. Offline/cloud-save и миграция на TypeScript не реализованы. Лицензия собственного кода не выбрана.
