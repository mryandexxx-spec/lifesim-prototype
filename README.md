# LifeSim — 0.5b.1 · Более цельные силуэты

Оригинальный стилизованный 3D-симулятор жизни для iPhone Safari.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Новое в 0.5b.1

- **Плечи:** отдельные круглые плечевые «шары» заменены более узкими продолговатыми рукавами, заходящими под корпус. Расширена верхняя часть туловища, чтобы скрыть резкий переход к рукам.
- **Руки:** более тонкие предплечья и маленькие кисти с перекрытием у манжет, без заметного разрыва между частями.
- **Таз и ноги:** удлинены верхние части ног, которые заходят внутрь таза; более естественный непрерывный силуэт и аккуратнее посадка обуви.
- **Ограничение:** это ещё простая процедурная геометрия, не полноценная бесшовная деформируемая сетка. Качество визуала нужно оценить на iPhone.
- **Проверки:** новые тесты перекрытия элементов в плечах и тазу, контрактов поз/суставов и обратной совместимости сохранений.
- **Симуляция не изменена:** потребности, два жителя, отношения, разговоры/споры, пауза, ×3, автономность и сохранения работают по старым правилам.

## Следующий этап

**0.5b.2 — плавные анимационные переходы, походка, выразительные жесты и эмоции.** Не входят в 0.5b.1.

## Архитектура

PlayCanvas 2.24.1 по CDN, JavaScript ESM, процедурная геометрия создаётся один раз в `src/characters.js` и интегрируется в `src/game.js`. Независимое ядро симуляции в `src/simulation.js`, `src/household.js`, `src/psychology.js`, `src/navigation.js`, `src/relationships.js`.

Прежний ключ localStorage `lifesim.room01.v1` и JSON `version:1` сохранены; никаких обязательных новых полей не добавлено.

## Ограничения

Пока нет динамической деформации плеч/кожи, полноценной мимики, физического избегания жителей, облачных сохранений или offline service worker. Время кадра/FPS/температура на реальном iPhone не измерялись. TypeScript пока не внедрён.

Лицензия на собственный код проекта ещё не выбрана; PlayCanvas лицензируется отдельно.
