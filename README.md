# LifeSim — Room 01 · 0.2

Стилизованный 3D-симулятор жизни для **Safari на iPhone**. Игра открывается без установки редактора, как обычный сайт.

## Играть

**https://mryandexxx-spec.github.io/lifesim-prototype/**

## Что нового в версии 0.2

- Алекс прокладывает путь вокруг кровати, дивана, стола, кухни и душевой (модуль A* с проверкой столкновений).
- Персонаж **ложится на кровать, садится на диван, принимает душ и открывает холодильник** с простыми анимационными эффектами.
- В статусе видно выполнение действия в процентах.
- Автономное поведение учитывает более срочные потребности и вечернее время; между самостоятельными задачами есть короткие паузы.
- Старые локальные сохранения v0.1 совместимы с v0.2. Можно прервать автоматическое действие ручной командой.
- Проверяемая игровая логика и навигация остаются отдельно от графического движка.

## Как играть

Проведи пальцем, чтобы повернуть камеру. Разведи два пальца, чтобы приблизить/отдалить.
Нажми метку предмета и выбери действие. Алекс подойдёт к предмету и использует его.
Справа: пауза, скорость ×1/×3 и сброс камеры. Внизу: потребности, сохранение, новая игра.

## Структура

- `index.html`, `styles.css` — интерфейс iPhone/Safari.
- `src/game.js` — 3D-сцена PlayCanvas, жесты, позы и интерфейс.
- `src/simulation.js` — автономные правила персонажа, время, потребности, действия.
- `src/navigation.js` — A*-навигация, препятствия и проверки проходимости.
- `tests/*.test.js` — тесты симуляции и маршрутов.
- `.github/workflows/pages.yml` — GitHub Actions: проверки и публикация на Pages.

**Стек:** JavaScript ESM без отдельной сборки, PlayCanvas 2.24.1 через CDN. Компоненты core независимы от PlayCanvas. TypeScript и сборщик предусмотрены как следующий этап после проверки стабильности.

## Тестирование

`npm test` — проверки логики и навигации. Для локального запуска: `python3 -m http.server 8000` и открыть `http://localhost:8000`.

## Известные ограничения

Это **ранний прототип**. Анимации позы и переходов упрощены; навигационная сетка рассчитана только на неизменяемую комнату, без динамических препятствий. Риг и полноценная анимация персонажей появятся позже. Нет облачного сохранения, сервис-воркера и гарантии офлайна; `localStorage` может быть очищен. Движок и шрифты загружаются через CDN, поэтому для первого запуска нужен интернет.

Публичные исходники не означают выдачу открытой лицензии на сам проект. Лицензия игры пока не выбрана; PlayCanvas — MIT.
