# LifeSim — browser prototype

Экспериментальный симулятор жизни для **iPhone Safari / PWA**. Разработка ведётся с приоритетом мобильного браузера; нативная упаковка iOS/Android рассматривается позже.

## Цель первой версии

Небольшая интерактивная 3D-квартира с одним управляемым персонажем, камерой, предметами, потребностями, действиями и локальным сохранением.

## Техническое направление

- **PlayCanvas** — предварительно выбранный веб-3D-движок; решение будет подтверждено тестами в Safari на iPhone.
- **TypeScript** — игровой код.
- **Отдельное ядро симуляции** — логика времени, потребностей и действий не должна зависеть от рендера.
- **PWA и offline-first** — после появления первой рабочей сборки.

Проект пока **не содержит опубликованной игровой сборки**. Планирование, продуктовые решения и закрытые материалы ведутся в отдельном приватном репозитории.

## Публичный репозиторий

Здесь находятся только материалы, необходимые для самой игры: исходный код, открытая техническая документация, игровые ассеты с разрешёнными правами, тесты и конфигурация сборки. **Не размещать** здесь продуктовые планы, закрытые заметки, токены, пароли или внутренние коммерческие документы.

## Правовой статус

Публичность GitHub-репозитория сама по себе **не означает**, что код открыт под свободной лицензией. Лицензия проекта пока не выбрана. Не добавляйте сторонние ресурсы без проверки условий их использования.

## Статус

**Этап 0 — организация проекта.** Следующая инженерная задача: технический 3D-прототип для проверки производительности, сенсорного управления и загрузки на iPhone.
