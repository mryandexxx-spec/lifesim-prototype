# LifeSim — 0.4a · Два жителя

Оригинальный стилизованный 3D симулятор повседневной жизни для **Safari на iPhone**.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Новое в 0.4a
- В одной квартире теперь **Алекс и Мира** — два отдельных персонажа с различимой внешностью.
- В нижней части экрана появилась пара кнопок **«Алекс» / «Мира»**: выбор управляемого жителя.
- Каждый имеет собственные голод, энергию, гигиену, досуг, настроение, желание, память, положение и действия.
- Ручные команды предметам направляются только выбранному жителю. Предмет не может использоваться сразу двумя.
- Глобальная кнопка **«Авто ВКЛ/ВЫКЛ»** управляет обоими жителями, с прежней 12-секундной задержкой перед самостоятельными действиями. Пауза/ускорение относятся к общей квартире.
- Старые сохранения 0.1–0.3.1 совместимы; прежние показатели и локальные данные Алекса остаются. Новая Мира добавляется автоматически.

## Как играть
Внизу выбери Алекса или Миру, затем нажми на предмет, чтобы дать задачу. Карточка выбранного жителя открывает панель характера, желания и воспоминаний. Справа управление временем и автономностью.

## Структура
- `src/household.js` — два жителя, независимо исполняемые действия и миграция локального сохранения.
- `src/simulation.js`, `src/psychology.js` — независимая симуляция и психология.
- `src/navigation.js` — A* маршруты вокруг статичной мебели.
- `src/game.js` — процедурная 3D-сцена, персонажи, визуальные состояния, UI.
- `index.html`, `styles.css` — мобильный интерфейс.
- `tests/*.test.js` — регрессионные тесты ядра и миграции.
- `.github/workflows/pages.yml` — CI и GitHub Pages.

JavaScript ESM без обязательного сборщика, PlayCanvas 2.24.1 с закреплённого CDN; TypeScript ещё не внедрён.

## Что дальше
**0.4b** добавит разговоры и разногласия, шкалу отношений и социальные эмоции. Пока персонажи только живут рядом, без социального взаимодействия.

## Ограничения
Ранний прототип: простой процедурный риг, две отдельные системы маршрутов, статичная мебель, нет физического избегания столкновений жителей друг с другом, offline, облачных сейвов или полноценного PWA. Сейвы в localStorage могут быть удалены браузером. Внешние CDN требуют интернета.

Публичная доступность исходников не означает предоставления лицензии на собственный код. PlayCanvas распространяется по MIT.
