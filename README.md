# LifeSim 0.6c — двуспальная кровать с двумя местами

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Что изменилось

Владелец оценил анимацию походки 0.6b.1 на iPhone как «Ходят смешно ) но пока оставим. Движемся дальше». Походку оставляем временно, её естественность остаётся задачей позднейшей полировки. Следующий утверждённый этап — **0.6c**, кровать.

- Двуспальная кровать получила **два независимых спальных места**: левое (по умолчанию Алекс) и правое (по умолчанию Мира). Оба могут спать одновременно, независимо пополняя энергию. Каждый занимает свою половину; если одна освобождается, другая остаётся занятой.
- Для каждого места отдельная **проходимая точка подхода сбоку**; A* ведёт к соответствующей стороне кровати, а не к одной общей точке.
- Новая **плавная визуальная последовательность**: подход с выбранной стороны → поворот к матрасу → перемещение на край → укладывание на свою подушку. При выходе — обратное вставание, после которого можно идти по следующему маршруту.
- Два раздельных покрывала и подушки делают независимые половины кровати визуально читаемыми.
- Сохранения **совместимы** с прежним ключом `lifesim.room01.v1` и JSON `version:1`: необязательное поле `action.bedSlot` хранит выбранную половину, старые действия сна без него автоматически получают безопасное место. Повторная загрузка не объединяет персонажей в один слот.
- Другая мебель всё ещё допускает **одного** пользователя одновременно. Автономный сон, ручное управление, пауза, ×3, камера, диван и другие действия сохраняются.
- Реализованы отдельные чистые модули `src/bed-layout.js` и `src/bed-transition.js`, регрессионные тесты `tests/bed.test.js`.

## Проверка на iPhone

Убедись, что на странице написано **prototype / 0.6c**. Поставь паузу и отключи «Авто», затем возобнови время. Отправь Алекса спать, переключись на Миру и **тоже отправь спать**: оба должны подойти с разных сторон, лечь на разные половины и спать одновременно. Отправь одного к холодильнику: сначала он должен встать, второй продолжить спать. Потом проверь сохранение/перезагрузку игры, а также диван и свайп-камеру.

Автоматические проверки не доказывают визуальную естественность в реальном iPhone Safari: окончательная приёмка требует твоей оценки.
