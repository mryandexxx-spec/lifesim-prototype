# LifeSim 0.6e.1 — мозаичная приватность в душе

**Игра:** https://mryandexxx-spec.github.io/lifesim-prototype/

После принятой владельцем на iPhone версии 0.6d реализован этап душа 0.6e. Обновление **0.6e.1** по отзыву владельца заменяет глухой privacy-бокс на **оригинальное морское стекло / цветную пиксельную мозаику** — три округлых элемента одного облака, объединённых общей непрозрачной процедурной sRGB-текстурой 256×256 пикселей. Это не blur и не копия эффекта The Sims/EA: один GPU upload, три простых меша, без постпроцесса и per-frame генерации. Персонаж по-прежнему полностью скрыт на фазах privacy, никакие ракурсы/отмена/загрузка не показывают раздевание.

- **Вход:** точка подхода в проходе справа от душевой, поворот и короткое движение к центру кабины, с подъёмом на реальную высоту платформы. Выход выполняется обратно до начала следующего маршрута.
- **Приватность:** округлое мозаичное облако с непрозрачными цветными плитками заменило сплошную коробку; весь avatar по-прежнему скрыт в состоянии privacy. Нет обнажённой модели и нет прозрачного слоя.
- **Переодевание:** только после закрытия экрана обычная одежда заменяется на полностью закрывающую условную одежду для душа. До открытия экрана обычная одежда восстанавливается. При отмене или загрузке в середине процесса тот же безопасный порядок сохраняется.
- **Мытьё:** капли воды и жесты рук появляются только после закрытия privacy-экрана. Вода выключается до переодевания обратно. Гигиена повышается только во время стадии воды, общее восстановление за действие сохранено; душ не прерывается из-за раннего достижения 100%.
- **Управление:** Алекс и Мира используют одну и ту же последовательность, душевая остаётся эксклюзивной, ручные и автономные задачи работают, пауза останавливает анимацию, ускорение ×3 согласовано с игровым временем. Временное состояние выхода блокирует новый маршрут до окончания.
- **Совместимость:** тот же ключ `lifesim.room01.v1`, `version:1`. Стадия на загрузке выводится из прежнего `action.elapsed`. Визуальные флаги и позиции маски не добавляются в сохранение.

## Автоматические проверки

```sh
npm ci
npm test
```

`src/shower-interaction.js` — независимые от PlayCanvas стадии/геометрия/выход. `src/privacy-mosaic.js` — детерминированная непроницаемая текстура и одноразовый upload с sRGB. `tests/privacy-mosaic.test.js` проверяет непрозрачность всех пикселей, вариативность плиток, material depth write, количество загрузок на GPU, подключение к renderer и прежний privacy timeline. `tests/shower.test.js` проверяет доступ к душевой по A*, инварианты приватности на каждом промежуточном шаге, обновление потребностей по стадиям воды, отмену, покрывающий костюм, обе личности, паузу, перезапуск и v1-сохранения.

В браузере используется закреплённая версия PlayCanvas 2.24.1 по CDN; исходники — JavaScript ES modules без обязательной локальной сборки. TypeScript не внедрён.

## Проверка на iPhone

Убедиться, что в шапке показано **prototype / 0.6e.1**. Отключить Авто, отправить Алекса в душ. Проверить: подходит через боковой проход, входит без скольжения, цветная мозаика появляется до воды/переодевания, вода выключается до открытия, Алекс выходит одетым и может сразу выполнить новую команду. Повернуть камеру двумя пальцами во время душа и проверить, что персонаж полностью скрыт. Повторить за Миру, затем проверить паузу, ×3, смену действия во время купания, reload в середине душа и сохранность кровати/холодильника/дивана.

**Статус:** Node-тесты и публикация GitHub Actions отдельно от реальной визуальной приёмки мозаики на iPhone. Инструментальные FPS/нагрев и WebGL Safari E2E не проводились. Offline/cloud-save нет. Лицензия собственного кода не выбрана.
