# LifeSim — 0.5b.2 · Движения и эмоции

Оригинальный стилизованный симулятор жизни для Safari на iPhone.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Что изменилось в 0.5b.2

- Ходьба, движения рук, переход к дивану/кровати, действия с холодильником и душем теперь **постепенно меняют углы суставов** вместо мгновенного переключения поз.
- В спокойном состоянии персонажи слегка дышат и двигаются; при разговоре жесты мягче, при споре более энергичные.
- На лицах изменяются угол бровей, размер улыбки и открытость глаз в зависимости от **существующего настроения**. Добавлены редкие короткие моргания; сон закрывает глаза.
- Шаги к собеседнику теперь используют анимацию ходьбы, в том числе когда персонаж идёт к разговору.
- Визуальные состояния не записываются в сохранения и не меняют игровые решения.
- Плечи и стыки, обновлённые в 0.5b.1, сохранены.

## Техническое устройство

`src/animations.js` — независимая от PlayCanvas расчётная анимация с экспоненциальным сглаживанием и рендер-адаптером. `src/characters.js` отдаёт дополнительные ссылки на брови и рот; контракт старых суставов/поз сохранён. `src/game.js` в каждом кадре применяет результат для Алекса и Миры. При паузе анимационные часы и состояние не изменяются.

PlayCanvas 2.24.1 по CDN, JavaScript ES modules, GitHub Pages. `npm test` и CI проверяют исходники/регрессии, затем обновляют сайт.

## Сохранения и ограничения

Старый ключ `lifesim.room01.v1` и `version:1` неизменны; автономность, отношения, память и потребности двух жителей работают по прежним правилам. Стилизация всё ещё использует простую процедурную геометрию, не цельную skinned mesh. Нет измеренного FPS или подтверждённой производительности на реальном iPhone для этой версии. Offline/облачных сейвов нет, TypeScript пока не внедрён.

Лицензия на собственный код не выбрана.
