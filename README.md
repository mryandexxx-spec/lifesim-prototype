# LifeSim 0.5b.4 — исправленная посадка и вставание

Оригинальный стилизованный симулятор жизни для iPhone Safari.

**Играть:** https://mryandexxx-spec.github.io/lifesim-prototype/

## Изменения по отзывам на 0.5b.3

Владелец проверил на iPhone новую позу («Норм»), но заметил погружение тела в диван и неестественное перемещение в сидячее положение.

- **Плавная последовательность:** подойти спереди к дивану → сделать небольшой шаг к сиденью → развернуться спиной → согнуть колени и сместиться назад → опуститься на подушку. При вставании — обратный переход с выпрямлением ног до начала следующего маршрута.
- **Без проваливания:** таз поднят до высоты, при которой низ тела остаётся над поверхностью сиденья; ноги и обувь согласованы с высотой пола.
- **Правильный подход:** маршрут A* теперь ведёт к проходу спереди дивана, а не через боковой подлокотник. Журнальный столик немного сдвинут, геометрия навигации соответствует изображению.
- У Алекса и Миры отдельный transient-контроллер сидения, одинаковый для ручного отдыха и автономности. При паузе он останавливается, не зависит от ×3.
- **Совместимость:** симуляция отдыха и сохранения `lifesim.room01.v1`/`version:1` остаются прежними; меняются лишь координаты подхода и визуал.

## Проверить на iPhone

Открой **0.5b.4**. Направь Алекса на диван и проследи за полным движением до посадки; посмотри, не проваливается ли таз. Затем дай новую команду — персонаж сначала должен встать. Повтори с Мирой, проверь паузу, старые предметы и сохранение.

## Технологии

PlayCanvas 2.24.1 CDN, JavaScript ES modules, GitHub Pages. `src/sofa-transition.js` содержит чистую математику перехода, `src/pose-config.js` — единую геометрию, `src/game.js` — визуальный контроллер; симуляция независима от PlayCanvas. `npm test` запускает Node-тесты, Pages Actions включает синтаксические проверки.

**Ограничения:** стилизованная процедурная геометрия, без skinned mesh/IK и ещё без реальной проверки версии 0.5b.4 на iPhone. FPS/нагрев не измерены. Нет offline/облачных сейвов, TypeScript не внедрён, лицензия собственного кода не выбрана.
